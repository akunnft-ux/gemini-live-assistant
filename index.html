Lumi asisten suara · Gemini Live
Siap

Tekan mikrofon untuk mulai ngobrol.

Tekan Spasi untuk mulai / berhenti. Bicara saat assistant masih bicara untuk menyela (barge-in). Headphone disarankan agar tidak terjadi feedback.

Transkrip

Transkrip percakapan muncul di sini, live. Tekan mikrofon di kiri untuk memulai.

Transkrip hanya ada di halaman ini — tidak dikirim ke server mana pun selain Gemini dan hilang saat tab ditutup.

Pengaturan

Ambil dari aistudio.google.com/apikey. Disimpan hanya di localStorage browser ini, tidak pernah masuk repository.

localStorage tidak tersedia di konteks ini (kemungkinan dibuka lewat file:// di browser tertentu). Pengaturan tidak akan tersimpan.

Boleh isi id model Live API lain sesuai kuota key kamu.

Otomatis = assistant mengikuti bahasa yang kamu pakai.

Tentang aman: aplikasi ini murni client-side, jadi API key tersimpan di browser dan secara teknis bisa dilihat siapa pun yang memakai aplikasi ini di perangkat yang sama. Untuk pemakaian publik, pakai key yang dibatasi (API restrictions + HTTP referrer allowable) agar tidak bisa disalahgunakan.
